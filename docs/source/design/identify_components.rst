==================================================
Identifying Components of Your Transactive Network
==================================================

When designing a transactive network using TENT, system modelers must identify five primary entity types:

1. **Balance Boundaries (Transactive Nodes)**:
   Determine the geographical, electrical, or organizational boundaries that define each agent (e.g., individual commercial buildings, feeder substations, microgrid islands).

2. **Local Generation & Storage Assets**:
   Identify controllable distributed generators (solar PV with smart inverters, battery storage, diesel/gas backup gensets).

3. **Flexible & Controllable Loads**:
   Identify building thermal systems (HVAC, chillers, heat pumps), electric water heaters, and EV fleet chargers that can modulate demand.

4. **Transactive Neighbors & Suppliers**:
   Define electrical connections between nodes, bulk utility wholesale feeds, and peer-to-peer power exchange lines.

5. **Environmental & External Forecasts**:
   Determine weather data sources, outdoor air temperature feeds, and dynamic utility tariff schedules required for lookahead scheduling.
