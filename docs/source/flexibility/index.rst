================================
Flexibility Modeling Framework
================================

TENT incorporates the **Flexibility Model Interface (FMI)** under ``tent.flexibility``. FMI provides a unified schema, protocols, and simulator adapters for modeling the physical flexibility of any power-consuming or generating asset.
